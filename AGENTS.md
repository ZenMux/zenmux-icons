# zenmux-icons

- `icons/*.svg` and `metadata.json` are the asset inputs.
- `src/` and `static/` are generated. Run `npm run generate`; do not edit them by hand.
- Preserve original colors, transparency, viewBoxes, and internal SVG references.
- Run `npm run generate`, `npm test`, and `npm run check` before committing.
- Keep source-system integrations, credentials, raw responses, and private provenance out of this repository and its history.
- This repository is publicly visible. Keep internal source adapters separate; public visibility does not grant an open-source license. Do not publish npm packages or change licensing without an explicit request.
- Document non-trivial design changes under `docs/sdd/`.
