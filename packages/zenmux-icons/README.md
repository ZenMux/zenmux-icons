# zenmux-icons

Official ZenMux package information placeholder.

The React icon library will be maintained as **@zenmux/icons**. That package has not
been published yet. This package does not contain React components or icon artwork
and does not automatically install or forward to the future package.

```js
import { packageName, repository, status } from 'zenmux-icons';
// packageName: "@zenmux/icons"
// status: "unreleased"
```

There is only one planned implementation of the icon library, under @zenmux/icons.
This unscoped package records its canonical name and repository.
